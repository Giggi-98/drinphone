## Correzioni
- Salvando le credenziali API di un PBX la finestra si chiude subito: prima
  restava su "Connessione…" finché la prima lettura dal PBX (rubrica
  compresa) non era finita. La lettura continua in sottofondo e il suo stato
  si vede nel pannello del PBX.
- Se il salvataggio delle credenziali non riesce, il pulsante torna attivo e
  compare un messaggio, invece di restare bloccato.

## Sicurezza
- Se le credenziali API nuove non si possono salvare, l'accesso del PBX
  precedente viene comunque chiuso e la connessione riparte con le
  credenziali rimaste.
- Un avvio o un canale eventi ancora in corso sul PBX precedente non
  rimettono più i suoi dati sulla connessione con le credenziali nuove.
